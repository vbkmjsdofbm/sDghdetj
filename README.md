# 天赋方向测试 · 测一测你的天赋藏在哪个方向

单页静态产品，零依赖、纯前端。

## 包内容

- `index.html` —— 唯一入口，已包含全部样式、交互、32 道题库与 10 类天赋文案。

## 特性

- 无外部图片、无外部字体、无第三方 JS 库，全部内联，断网也能打开。
- 无后端、无接口、无数据库，不采集任何用户数据。
- 适配手机与电脑，选完自动翻页，支持返回上一题、键盘 1–4 / A–D。
- 结果页包含天赋浓度、天赋分布前三、可落地的职业方向、发挥建议与避坑提醒。

## 机制说明

- 32 题，每题 4 个选项，每个选项绑定 1 类天赋（共 10 类）。
- 每选一次就给对应天赋加 1 分，最高分即为结果。
- 天赋浓度 = 最高分 / 32，结果页按百分比展示，是真实作答占比，不是预设分数。
- 同分处理：先看第 32 题落在哪一类；仍未分出时按 组织 → 语言 → 探索 → 创意 → 共情 → 逻辑 → 动手 → 审美 → 秩序 → 深耕 的优先顺序取前者。

## 部署方式

1. **直接上传**：把 `index.html` 放进站点根目录或任意子目录即可，不需要构建、不需要安装依赖。
2. **zip 上传**：支持整包上传的静态托管（对象存储静态网站、云托管等）可直接上传本压缩包。
3. **本地预览**：双击 `index.html` 用浏览器打开即可完整运行。

## 注意

- 入口文件名必须是 `index.html`，改名后部分托管会找不到首页。
- 页面里没有绝对路径引用，放在子目录也能正常工作。
- 修改文案：题库在 `<script>` 内的 `Q` 数组，选项形如 `["选项文字","t3"]`；结果是 `RES` 对象（t1–t10），`dirs` 里每项为 `[方向标签, 具体岗位]`，改文字不必动逻辑。
- 对外发布建议保留页脚“仅供自我认识参考，不构成职业规划或专业测评建议”，不要宣传为专业测评或保证就业。
